# CoolPlayer 🎧

Локальный музыкальный плеер для Android: Jetpack Compose + Media3/ExoPlayer.

## Возможности
- Локальная библиотека (все тома, включая SD), поиск, фильтры, сортировка, sticky-заголовки
- Плеер в стиле современных приложений: переливы темы, обложка с жестами, тексты песен (LRCLIB, синхронизация ±0.5s, встраивание в файл)
- Системный эквалайзер с нормализованными пресетами
- Динамические темы + авто-цвет из обложки
- Сон-таймер, скорость воспроизведения, восстановление сессии после перезапуска
- Виджет на рабочем столе, медиа-уведомление с обложкой
- Открытие аудио из внешних приложений (ACTION_VIEW)
